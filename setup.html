إعداد قسم المدرب

تُنفَّذ هذه الخطوات مرة واحدة فقط، وتستغرق حوالي ١٠ دقائق من الجوال. بعدها تُحفظ بيانات المتدربين في جدول Google داخل حسابك.

١انسخ كود الخادم

اضغط الزر لنسخ الكود كاملًا، ولا تعدّل فيه شيئًا.

٢افتح Google Apps Script

  1. اضغط الزر لفتح الموقع في Safari، وسجّل دخولك بحساب Google.
  2. مهم على الآيفون: اضغط زر aA في شريط العنوان ← طلب موقع سطح المكتب، لأن الموقع لا يعمل بنسخة الجوال.
  3. اضغط New project (مشروع جديد).
فتح Google Apps Script ↗

٣الصق الكود واحفظه

  1. اضغط داخل مساحة الكود، ثم حدّد كل الموجود فيه (اضغط مطوّلًا ← تحديد الكل) واحذفه.
  2. اضغط مطوّلًا ← لصق.
  3. اضغط أيقونة الحفظ 💾 في الأعلى.
  4. يمكنك تغيير اسم المشروع من أعلى الصفحة إلى فيزياء 101 (اختياري).

٤امنح الصلاحيات

  1. في الشريط العلوي، اختر الدالة setup من القائمة، ثم اضغط Run (تشغيل).
  2. تظهر نافذة Authorization required ← اضغط Review permissions واختر حسابك.
  3. تظهر رسالة “Google hasn’t verified this app”. هذا طبيعي لأن الكود خاص بك: اضغط Advanced ثم Go to … (unsafe).
  4. اضغط Allow (سماح).
يطلب الكود صلاحيتين فقط: إنشاء جدول Google في حسابك ليحفظ فيه بيانات المتدربين، والاتصال بخدمة خارجية ليعمل المساعد الذكي.

٥انشره كتطبيق ويب

  1. اضغط الزر الأزرق Deploy ← New deployment.
  2. اضغط أيقونة الترس ⚙️ بجانب Select type واختر Web app.
  3. Execute as: اختر Me.
  4. Who has access: اختر Anyone ← مهم جدًا حتى يستطيع المتدربون الدخول.
  5. اضغط Deploy، ثم انسخ الرابط تحت Web app URL. ينتهي الرابط بـ /exec.

٦الصق الرابط واختبره

٧أضف الرابط إلى موقعك في GitHub

  1. اضغط نسخ محتوى config.js.
  2. اضغط فتح ملف config.js في GitHub وسجّل دخولك إن طُلب منك.
  3. احذف كل النص الموجود في الملف، والصق المنسوخ.
  4. اضغط Commit changes مرتين.
  5. انتظر دقيقة حتى يحدّث Render الموقع.
