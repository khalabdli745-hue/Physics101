# حارس منصة الفيزياء 101

يقارن كل تعديل بأحدث فرع معتمد `approved-NNN` (فرع محمي لا يتغير)، ويفشل عند أي تغيير خارج النطاق.

- `scope.json`: نطاق التعديل الحالي (الملفات، الدروس `u-l`، مكون مشترك، الصوت). يكتب مع كل تعديل ويراجعه المدرب في طلب الدمج.
- `static.py`: العلامات المعتمدة، النطاق وتقييد التغيير بـ `data-les`، منع النسخ القديمة، أرقام الإصدارات، نطق كل الجمل.
- `shape.py` + `shapecmp.py`: بصمة كل الدروس وتبويباتها على اللابتوب والجوال، للمرجع والجديد، ومقارنتهما.
- `registry.json`: العلامات المعتمدة. `voicegold.json`: أمثلة الصوت الثابتة.
- لا بصمات مرجعية مخزنة: المرجع يعرض مباشرة من فرع approved في كل فحص.
